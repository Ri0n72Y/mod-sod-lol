# Shape of Dreams × League fan mod experiments

Experimental, community-driven modding research for **Shape of Dreams**.

The first proof of concept uses **Lacerta** as the host Traveler and explores a Caitlyn-inspired identity kit:

- Identity / passive: Headshot
- Q: Piltover Peacemaker
- W: Yordle Snap Trap
- E: 90 Caliber Net
- R: Ace in the Hole

The initial implementation focuses on runtime `SkillTrigger` registration, identity-gated exclusive Memories, and safe lifecycle cleanup. Model, animation, audio, and other binary assets are intentionally excluded until their redistribution licenses are verified.

## Status

Early experiment. The repository is being bootstrapped from the official Shape of Dreams mod API and community source examples.
